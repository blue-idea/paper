## Layout & Spacing

A tri-pane architectural frame inspired by macOS native applications:

1. **Navigation Sidebar (Left, 220pxâ€“280px)**: Collapsible. Contains project binder, chapters, character index, and timeline. Frosted glass backing.
2. **Main Sanctuarial Canvas (Center, Flexible)**: Houses the floating "Paper Sheet". Remains centered with infinite scroll margins (`space-2xl` minimum padding top/bottom).
3. **Inspector & Companion Rail (Right, 280pxâ€“360px)**: Collapsible. Contains AI copilot notes, historical revisions, and metadata cards.

### Layout Adaptations
- **Full Immersion (Zen Mode)**: Left and right sidebars collapse with a 200ms cubic ease. The editor expands with `margin: auto`, keeping the `680px` prose sheet perfectly centered.
- **Split Screen / Dual Desk**: When window width drops below `1100px`, the companion rail automatically docks into an overlay sheet or collapses to an icon bar.
- **Window Padding**: Internal window elements maintain an 8px grid offset from the OS window boundary to account for macOS window squircle clipping.

## Elevation & Depth

Paper Isle relies on **Tonal Layers** combined with **macOS Vibrancy Glassmorphism** rather than synthetic high-drop shadows.

### Elevation Hierarchy
- **Level 0 (App Canvas Base)**: `#F6F1E7` in light mode, `#1C1D21` in dark mode. Solid substrate.
- **Level 1 (Sidebars & Chrome)**: Frosted glass vibrancy layer. Light mode uses `rgba(246, 241, 231, 0.72)` with `backdrop-filter: blur(24px) saturate(180%)`. Border: 1px hairline `rgba(43, 42, 40, 0.08)`.
- **Level 2 (Paper Desk Sheet)**: The manuscript page floats over Level 0. Background `#FAF7F2` with an ambient shadow: `0 4px 20px -2px rgba(43, 42, 40, 0.04), 0 1px 3px 0 rgba(43, 42, 40, 0.02)`.
- **Level 3 (AI Companion Popover & Overlays)**: Background `#FAF7F2` with ambient warm shadow: `0 12px 32px -4px rgba(43, 42, 40, 0.08), 0 4px 12px -2px rgba(43, 42, 40, 0.04)`.
- **Level 4 (Modal Dialogs / Export Suites)**: Centered overlay backed by a translucent scrim (`rgba(28, 29, 33, 0.25)`).

## Shapes

The design uses Apple-spec squircle (continuous corner curvature) geometry to maintain a tactile, organic paper feel.

- **Window Shell**: `12px` border radius conforming to native desktop conventions.
- **Manuscript Sheet & Floating Panes**: `10px` border radius (`rounded-lg`).
- **Interactive Controls (Buttons, Inputs, Pill Badges)**: `8px` corner radius.
- **Cinnabar Stamp Badges**: Traditional seal shape with slightly rounded square edges (`4px`) or circular stamp motifs.
- **Hairlines**: All dividers and component outlines use a strict `1px` (or `0.5pt` on Retina displays) stroke width.

## Components

### 1. Unified macOS Toolbar
- Integrates traffic lights on the left with a `12px` lead.
- Center hosts document title, chapter badge, and word-count status in muted ink tone.
- Right anchors the "Focus Mode", "AI Whisper", and "Export" actions.
- Surface: Glass vibrancy with a bottom boundary stroke (`#E4DDD1`).

### 2. Buttons
- **Primary Action (Cinnabar Button)**: Filled `#B5473A` with `#FAF7F2` text. Hover transitions to `#A23D31`. Active scale down `0.98`. Focus ring: `2px solid rgba(181, 71, 58, 0.35)`.
- **Ghost / Tool Button**: Transparent background, `#2B2A28` icon/text with `1.5px` stroke weight. Hover introduces `rgba(43, 42, 40, 0.05)` fill with `8px` roundedness.

### 3. AI Literary Margin (The Companion Card)
- Sits unobtrusively alongside the writing stream.
- Left-bordered with a `2px` stroke of Celadon (`#6FA39A`).
- Typography uses `caption-marginalia` in faded ink.
- Provides contextual suggestions, rhetorical variations, and historical allusions without obscuring prose.

### 4. Inputs & Search Fields
- Native Spotlight-style input.
- Background: `rgba(228, 221, 209, 0.45)`. Text: `#2B2A28`. Placeholder: `#7A756D`.
- Height: `28px` for compact table inputs, `34px` for main search and command palette (`Cmd+K`).
- Border: `1px solid transparent`; switches to `1px solid #B5473A` upon active focus.

### 5. Checkboxes, Toggles & Radios
- Selection indicators borrow from cinnabar ink marks.
- Checkboxes: `16px x 16px` with `4px` radius. Active state filled with `#B5473A`, hosting an ivory checkmark.
- Radio buttons: Classic concentric circle with an inner `#B5473A` dot.

### 6. Chips & Status Badges
- Used for metadata tags (e.g., Draft, Polished, Act I, POV).
- Height: `22px`, font: `label-ui-sm`.
- Subtle borders tinted by category: Celadon (`#6FA39A`), Indigo (`#6B84A8`), or Ochre (`#B8803F`) with an `8%` alpha background fill.
